# Site Backup Streamer

Site Backup Streamer - простий WordPress-плагін для потокового завантаження резервних копій сайту з адмін-панелі.

Плагін додає віджет на головну сторінку WordPress Dashboard. Через нього адміністратор може:

- перевірити готовність середовища до експорту;
- порахувати приблизний розмір файлів сайту;
- завантажити файли WordPress як ZIP-архів;
- завантажити базу даних як SQL-дамп.

## Для чого він потрібен

Плагін корисний, коли потрібно швидко отримати резервну копію сайту без створення тимчасового ZIP-файлу на сервері. Архів файлів і дамп бази даних передаються напряму в браузер як потік відповіді.

Це зменшує потребу у вільному місці на диску, але все одно вимагає достатніх ресурсів PHP і стабільного з'єднання для великих сайтів.

## Можливості

- Віджет у WordPress Dashboard.
- Доступ тільки для користувачів із правом `manage_options`.
- Nonce-захист для запитів на завантаження.
- Потокове ZIP-завантаження файлів сайту.
- SQL-експорт бази даних через `mysqldump-php`.
- Перевірка PHP, Composer-залежностей, `pdo_mysql`, доступності `ABSPATH`, DB-констант і `php://output`.
- AJAX-сканування розміру сайту перед завантаженням.

## Вимоги

- WordPress із доступом до адмін-панелі.
- PHP 8.1 або новіший.
- Розширення PHP `pdo_mysql`.
- Composer-залежності з папки `vendor`.

Composer-пакети:

- `maennchen/zipstream-php`
- `ifsnop/mysqldump-php`

## Встановлення

1. Скопіюйте папку `site-backup-streamer` у `wp-content/plugins/`.
2. Якщо папки `vendor` немає, виконайте в директорії плагіна:

```bash
composer install --no-dev
```

3. Активуйте плагін у WordPress Admin -> Plugins.
4. Відкрийте Dashboard і знайдіть віджет "Резервна копія сайту".

## Використання

1. Переконайтеся, що всі перевірки у віджеті успішні.
2. Натисніть "Порахувати розмір", якщо хочете оцінити обсяг файлів.
3. Натисніть "Завантажити сайт", щоб отримати ZIP-архів файлів WordPress.
4. Натисніть "Завантажити базу даних", щоб отримати SQL-дамп.

Файли сайту зберігаються в архіві з префіксом `site/`. Якщо `wp-config.php` розташований на один рівень вище кореня WordPress, плагін також спробує додати його до архіву.

## Обмеження

- Плагін не створює автоматичні резервні копії за розкладом.
- Плагін не завантажує копії у хмарне сховище.
- Для дуже великих сайтів завантаження залежить від лімітів хостингу, браузера та стабільності HTTP-з'єднання.
- Символічні посилання та недоступні файли пропускаються.

## Безпека

Завантаження доступне тільки адміністраторам WordPress. Запити захищені nonce-перевірками, а перед стартом експорту плагін виконує базові системні перевірки.

Оскільки резервна копія може містити конфіденційні дані, зберігайте отримані ZIP та SQL-файли у безпечному місці.
