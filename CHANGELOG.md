# Site Backup Streamer

## Зміни

### 1.1.1 — підтримка PHP 8.1

- **Мінімальна версія PHP — 8.1** (була 8.3): плагін знову працює на хостингах з PHP 8.1 і 8.2.
  ZipStream повернуто до 3.1.1 — останньої версії для PHP 8.1; mysqldump-php лишається 2.13.
- Режим zero header (розміри файлу записуються після його даних) тепер задано явно, а не через
  типове значення бібліотеки. З ним ZipStream 3.1.1 пише архів байт у байт так само, як 3.2.2
  (перевірено на архіві 4,4 ГБ); без нього 3.1.1 записував би неправильні розміри в заголовки
  файлів після позначки 4 ГБ — у самій бібліотеці це виправлено лише в 3.2.2.

### 1.1.0 — авто-оновлення з GitHub і надійний експорт

- **Авто-оновлення:** плагін оновлюється з GitHub Releases стандартним механізмом WordPress; пакет
  перевіряється за SHA-256 перед встановленням.
- **Виправлено битий ZIP на хостингу з малим лімітом пам'яті.** ZipStream читає кожен файл блоками
  по 16 МБ, а `admin-post.php` не піднімає ліміт пам'яті, як це роблять сторінки адмінки. PHP падав
  одразу після заголовка першого файлу архіву, і WordPress дописував у завантаження сторінку
  «критичної помилки». Тепер ліміт піднімається до `WP_MAX_MEMORY_LIMIT`, а якщо пам'яті однаково
  замало, віджет показує червону перевірку «Пам'ять» і архів не запускається.
- **Виправлено:** одна недоступна папка обривала весь архів; тепер вона пропускається.
- **Виправлено:** файл із датою зміни раніше 1980 року обривав архів; тепер йому ставиться 01.01.1980.
- **Виправлено:** лічильник папок у скануванні був утричі завищений (рахував `.` і `..`).
- **Виправлено:** SQL-дамп знімався в `utf8` і замінював emoji на `?`; тепер — у кодуванні з'єднання
  WordPress (`utf8mb4`).
- Обірваний SQL-дамп тепер видно: повний закінчується рядком `-- Dump completed`, а при помилці
  дописується `-- ПОМИЛКА: дамп неповний`.
- **Безпека:** на multisite копію може завантажити лише адміністратор мережі.
- Якщо `wp-content` винесено за межі кореня WordPress (Bedrock), він тепер теж потрапляє в архів.
- Скасоване завантаження зупиняє експорт на сервері; постійне з'єднання з MySQL вимкнене.
- Мінімальна версія PHP — 8.3; оновлено ZipStream до 3.2 і mysqldump-php до 2.13.
