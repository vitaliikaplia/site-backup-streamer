# Site Backup Streamer

Уся документація для агентів — у Memo (MCP-сервер `memo`), проєкт **#27 site-backup-streamer**.
Почніть з `memo_structure` для проєкту 27: картка, карта й протокол роботи.

Після кожної завершеної задачі оновлюйте записи в Memo, а не MD-файли. Перед компактом запишіть
статус задачею в кімнаті `compaction`, після компакту — прочитайте її й закрийте.
