# Site Backup Streamer

## Опис плагіна

Site Backup Streamer - це простий WordPress-плагін для ручного створення резервних копій через Dashboard. Він додає віджет "Резервна копія сайту", доступний адміністраторам, і дозволяє окремо завантажити файли сайту та базу даних.

## Для чого використовується

Плагін потрібен для швидкого отримання резервної копії WordPress-сайту без запису готового архіву на диск сервера. Файли сайту передаються в браузер як ZIP-потік, а база даних - як SQL-файл.

## Основний файл

- `site-backup-streamer.php` - головний файл плагіна. Реєструє Dashboard-віджет, обробляє admin-post завантаження, виконує AJAX-сканування розміру сайту та запускає потоковий експорт.

## Основні залежності

- `maennchen/zipstream-php` - формує ZIP-архів у потоці відповіді.
- `ifsnop/mysqldump-php` - створює SQL-дамп бази даних.

## Поведінка

- Доступ до функцій має тільки користувач із правом `manage_options`.
- Завантаження захищене WordPress nonce.
- Перед експортом перевіряються PHP 8.1+, Composer autoload, `pdo_mysql`, доступ до кореня WordPress, DB-константи та `php://output`.
- Файли сайту скануються від `ABSPATH`; символічні посилання, недоступні або нечитабельні елементи пропускаються.
- База даних експортується з параметрами `single-transaction`, `add-drop-table`, `add-drop-trigger`, `routines` та `events`.

## Важливі зауваження для агентів

- Плагін має український інтерфейс, тому користувацькі тексти бажано залишати українською.
- Не змінюйте vendor-файли без явної потреби.
- Якщо змінюється логіка експорту, перевіряйте сумісність із API `ZipStream\\ZipStream` і `Ifsnop\\Mysqldump\\Mysqldump`.
- Плагін не має планувальника, фонового сховища або інтеграції з хмарними сервісами; це ручний інструмент потокового завантаження.
